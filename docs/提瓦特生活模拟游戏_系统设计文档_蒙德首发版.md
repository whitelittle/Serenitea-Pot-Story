提瓦特生活模拟游戏：系统设计文档

当前基线：蒙德首发版 · 尘歌壶长期生活模拟 · 设计整理稿 v0.1

本文整理当前已经明确或高度倾向的游戏设计。首发内容以蒙德（含龙脊雪山）为完整可长期游玩的区域；底层设计继续兼容未来璃月、稻妻、须弥、枫丹、纳塔、至冬扩展。

核心幻想：外面的世界给家里东西，家里的成长又让玩家走得更远；玩家不是完成一张任务清单，而是在这个世界生活。


## 1. 项目定位与设计原则


### 1.1 核心定位

玩家扮演可选择空/荧的旅行者，派蒙是唯一恒定的生活伙伴与引导者。

尘歌壶直接作为永久的家，不需要复杂来源解释或主线世界谜团。

弱主线、强系统、强生活感、强探索与收藏；不承担“拯救世界”式主剧情。

玩家每天的核心问题是“今天我想做什么？”，而不是“今天有哪些任务没清”。

外部世界负责发现；尘歌壶负责拥有、培养、制造、陈列与留下记忆。


### 1.2 不做的方向

不做每日/程序化公会委托刷取循环，不用FOMO和限时奖励驱动上线。

不做角色等级、经验书、突破、命座、圣遗物、天赋材料、树脂、周本材料等原神养成体系。

不做元素反应系统与复杂Build；元素保留为直接能力、环境交互与生活便利。

不做复杂战斗技能树、武器精炼循环、完美格挡等独立战斗成长系统。

不把NPC做成统一规格的送礼机器，也不把角色帮工做成劳动力卡牌。

不让后期家园变成机器阵列、箱子海或最优布局考试。


### 1.3 系统检查标准

任何新系统都应尽量与其他系统产生双向联系。如果一个系统只是“进去玩一下→拿奖励→结束”，需要重新评估。

发现 → 获取 → 带回家 → 培养/制作/陈列 → 产生新需求 → 再次出发。


## 2. 首发范围：只有蒙德

首发版本可以只实现蒙德，而且应把它当成完整游戏而不是残缺Demo。设计层面仍然把整个提瓦特视为未来可扩展结构。


| 方面 | 蒙德首发策略 |
| --- | --- |
| 地图 | 蒙德城、果酒湖、低语森林、星落湖、望风山地、风起地、清泉镇、晨曦酒庄、奔狼领、明冠峡、风龙废墟、鹰翔海滩、摘星崖、龙脊雪山及大量小区域。 |
| 内容密度 | 把原本分散到七国的制作预算投入季节、生态、NPC行为、图鉴、洞穴、天气、家园互动和长期变化。 |
| 长期成长 | 从“跨国横向扩张”改为“蒙德表层→不同生态→深层探索→能力回访→长期世界变化”。 |
| 未来扩展 | 新增国家同时增加新地区内容、旧地区新用途和尘歌壶新内容；旧存档无需重开。 |


### 2.1 蒙德内部必须足够深

蒙德不仅是温带平原。龙脊雪山承担第二种大型生态，海岸、湖泊、地下洞穴、山地、森林、城镇和遗迹继续提供差异。


### 2.2 能力门槛回收到蒙德

强化斧：大型倒木、硬木、厚根；同时开启旧地图隐藏路径。

高级镐：特殊矿脉、岩壁和更深洞穴。

船：果酒湖、海岸与离岸小岛探索；未来可自然扩展到稻妻/枫丹。

寒地准备：用于龙脊雪山深处，但以软准备为主，不做等级空气墙。

所有能力都应在旧区域产生回访价值，而不是单一区域钥匙。


## 3. 核心循环与系统关系

探索给家园资源与知识；家园给探索工具、料理、经济与准备。


| 输入系统 | 中间系统 | 输出/回流 |
| --- | --- | --- |
| 探索、采集、矿物、鱼类、生物 | 图鉴/知识 | 已知栖息地、用途、培养方法、旅行线索 |
| 农业、畜牧、钓鱼、采集 | 料理 | 自用、冒险准备、聚餐、关系、出售、图鉴 |
| 木材、矿物、植物、遗迹材料 | 制作/锻造 | 工具、家具、建筑、加工设备、旅行用品 |
| 生产与加工 | 经济 | 摩拉→建筑、工具、装修、旅行便利 |
| NPC与关系 | 知识传播 | 食谱、图纸、生态知识、邀请、个人故事 |
| 旅行发现 | 尘歌壶 | 种植、饲养、生态定居、展示、纪念 |

农业不能退化为“种→卖→买种→再种”；动物不能退化为“喂→产物→卖”；料理与制作是两个重要汇流系统，负责把大量资源重新连接到生活、关系、探索和家园成长。


## 4. 时间、季节与日常节奏


### 4.1 时间基线

建议28天/季、112天/年，作为内容规划基准；最终仍可调。

标准实际流动时间约15–18分钟/游戏日；菜单、地图、重要对话等暂停后，体感约18–25分钟。

可提供快节奏与悠闲时间速度选项。

传送不消耗游戏时间；尘歌壶与外界共享同一时间。

睡觉执行Day Tick：保存、作物、加工、动物、市场、商店、资源生态、NPC日程、天气与事件更新。


### 4.2 季节原则

季节改变生态、鱼虫、NPC活动、天气、植物生长、景观与料理，而不是只换贴图。

换季不让作物瞬间全死；植物可处于适宜、可生长、休眠、无法生长等状态。

冬季不是“不能种田所以去挖矿”的空档，要有冰湖鱼、冬季生态、室内活动、家具手工、人物来访和雪景摄影。

不做年度评分、季度KPI或强制完成度。


## 5. 尘歌壶：永久家园


### 5.1 空间成长

开局只给小屋、院子、小块田、工作台和池塘。完整地形从第一天就真实存在，远处可见树林、山坡、河流和草地；玩家随着能力与需求逐渐整理利用。

扩地主要是整理土地，不是向系统购买“区域2”。

前期亲手清理小块土地；中期大型整理工程项目化；后期开放更自由的规划。

扩张由需求产生：想建鸡舍→需要平地→整理草地，而不是“家园等级5解锁区域”。

不同方向有天然地形倾向，但不硬性分区：平地适合农牧、高地适合果园与观景、湿地适合水生生态等。


### 5.2 建筑与房屋

建筑采用可见模块化升级，而非纯“鸡舍Lv.3”：扩建禽舍、活动区、大饲料槽、自动饮水、收集箱、孵化区、保温等。

主屋通过选择房间扩建：厨房、餐厅、卧室、书房、工作室、收藏室、客房、派蒙的小空间。

施工可表现为数日可见过程，而不是瞬间黑屏完成。

道路、桥、地面、池塘与轻度地形改造在中后期开放；地形改造同时服务审美与生态。


### 5.3 家园生态

装修不使用“家具评分”作为核心驱动。环境布置应影响可见生态：花园吸引蝴蝶和蜜蜂，树林吸引鸟类，池塘吸引青蛙和蜻蜓，特殊植物组合可能吸引晶蝶定居。


### 5.4 防止后期工厂化

加工设备优先升级容量/队列，而不是复制几十台机器。

前期木箱→中期仓库→后期统一可搜索家园储存；生产设施可读取连接储存。

自动化负责去掉重复劳动，不替玩家决定种什么、卖什么、繁殖什么或如何布局。


### 5.5 家园五个自然阶段


| 阶段 | 典型状态 | 玩家感受 |
| --- | --- | --- |
| 落脚 | 小屋、小田、工作台、箱子、池塘 | 我有地方住了 |
| 农家 | 更大农田、鸡舍、果树、厨房扩建、道路 | 我开始在这里生活 |
| 庄园 | 牧场、工坊、仓库、鱼塘、蜂箱、房屋扩建 | 这里成为生活与生产中心 |
| 旅行者之家 | 温室、生态园、收藏室、客房、地区风格、特殊生物 | 旅行开始留在家里 |
| 小世界 | 树林、湖泊、湿地、花园、桥、瀑布、丰富生态 | 这是我的世界 |


## 6. 角色帮工与共同生活

角色可以帮忙，但核心是友情与共同生活，不是派遣劳动力。


### 6.1 两种形式


| 形式 | 作用 | 边界 |
| --- | --- | --- |
| 共同劳动 | 玩家与角色同时在场，收获、照顾动物、果园、做饭、整理家园 | 价值主要是陪伴感与情境对话 |
| 委托照看 | 高关系角色在玩家远行时维持基础家务 | 只能维持，不替玩家经营与决策 |


### 6.2 可以与不可以

可以：浇已种好的田、收普通成熟作物、喂动物、收普通动物产品、采成熟果实、搬普通材料、基础料理准备。

不可擅自：选择播种、砍树、出售、使用珍贵材料、安排繁殖、决定加工队列、改家园布局。

角色差异用性格和擅长活动表现，不使用“农业效率130%”式数值卡牌。

角色首先拥有自己的生活与日程，不应成为随叫随到的每日免费劳工。

共同劳动可自然触发角色知识、食谱、生态提示和专属对话。

后期大规模家园有三条并行解法：设施自动化、朋友偶尔帮忙、玩家主动选择少生产一点。游戏不要求最大产量。


## 7. 玩家、工具与元素


### 7.1 旅行者

移动保留走、跑、冲刺、跳、攀爬、游泳、滑翔、下落攻击等熟悉能力。

统一交互用于采集、对话、宝箱、门、坐下、抚摸、机器、收获、神像等。

轻量属性：生命、短期体力、食物/增益、元素能量；不设独立每日农活体力条。

战斗仅保留普通攻击、重击、闪避/冲刺、E、Q、食物治疗。


### 7.2 工具

生活工具与武器分开：锄头、浇水工具、斧、镐、鱼竿、捕虫工具等。工具升级主要解锁能力而不是纯速度。


| 工具 | 能力成长示例 |
| --- | --- |
| 斧 | 普通树枝/树木→大型倒木/硬木→古木/特殊木材 |
| 镐 | 普通矿→硬矿→特殊矿/岩壁 |
| 浇水 | 单格→小范围→更大范围；后期由设施自动化接管日常 |
| 鱼竿 | 基础水域→特殊水层/更稳定控制→稀有水域能力 |


### 7.3 元素

不做元素反应。元素是同一套战斗能力在环境中的自然延伸：水可浇小片田/灭火/加水，火可点火/融冰，风可吹落果实/清叶，岩可破普通岩石/形成临时踏脚，雷可激活机关，草可与特殊植物互动，冰可临时冻结水面或降温。元素不能替代长期设施和自动化。


## 8. 农业与植物生态

植物拥有内部生态需求：生长周期、温度、水、光、土壤、栖息环境、季节偏好、是否重复收获；UI只展示易懂摘要。

植物类别：一年生、重复结果、花卉、草药/地区植物、果树/藤本、特殊生态植物。

土壤只保留肥力与湿度等轻量属性，不做NPK/pH硬核模拟。

品质1–5星，受种子、土壤、水分、肥料、环境匹配、天气与照料影响；良好操作改变概率分布而非纯随机。

高品质产物有竞争用途：出售、留种、料理、加工、赠礼、节庆。

温室稳定温度与天气；后期生态花园处理高地、湿地等特殊环境。

野外负责高品质、稀有变体和种源；家园负责稳定与控制，避免家园种植杀死探索价值。


### 8.1 培养研究

第一次发现地区植物不等于立即可种。玩家可通过重复观察、种子获得、NPC/书籍知识和栖息地研究逐步掌握人工培养。


## 9. 畜牧、宠物与特殊生物

家畜=稳定生产；野生动物=观察发现；地区动物=旅行身份；宠物=陪伴。

不要求每日抚摸；良好饲料、环境、健康、户外活动与长期照料构成主要状态。

动物生命周期到成熟后停止，不自然死亡，不强制屠宰。

动物有轻量性格：温顺、活跃、懒散、害羞、贪吃、亲人、独立等。

早期手动喂食/收集/挤奶/剪毛；中期大槽与收集箱；后期自动喂食与集中收集。

宠物不承担生产KPI，可在家中形成真实行为。


### 9.1 特殊生物

晶蝶、仙灵等首先属于世界生态。尤其推荐“迁入/定居”而不是全部捕获：野外发现→了解栖息需求→在家创造环境→某天自然出现并逐渐稳定定居。


## 10. 料理、加工与食物

三层：原料加工→正式料理→生活/冒险/关系/经济用途。

料理是农业、畜牧、钓鱼、采集的重要汇流点。

食谱来自餐馆、人物教学、书籍、旅行、品尝、节庆、探索和实验。

不要求每次做菜玩小游戏；首次/手动有体验，熟练后支持自动与批量。

料理质量受原料、熟练、技能和手动表现影响。

NPC偏好可基于甜/咸/辣/酸/鲜/清淡/浓郁等风味，加少数特别喜欢的菜。

邀请吃饭应比日常送礼更重要。

加工设施按游戏时间工作，与厨房的即时/短时烹饪分开。


## 11. 经济、商店与市场

摩拉为主货币，避免多种手游货币。

收入路线并行：农业、畜牧、钓鱼、采集、矿业、料理、加工、探索、制作。

直接商店即时出售；家园出货箱次日结算。

轻量供需：持续大量倾销同一物品会缓慢压价但有价格底线，鼓励多样化而非惩罚。

节庆/季节带来需求变化；市场价格缓慢变化。

商店不仅卖东西，也展示未来可能性：鸡舍、蜂箱、鱼塘、自动化图纸等可提前被看见。

后期金钱主要流向装修、旅行便利、收藏、服装、稀有商品和大型家园项目，不靠荒谬天价硬吸钱。

传奇鱼、特殊生态记录、Boss纪念品、探索遗物等发现型内容不能直接购买。


## 12. NPC、关系与生活


### 12.1 NPC层级


| 层级 | 内容深度 |
| --- | --- |
| 普通居民 | 简单日程、公共事件，不做完整关系系统 |
| 功能/特色NPC | 中等日程、简单关系、少量事件与专业知识 |
| 核心角色 | 完整日程、关系、人物事件、邀请、尘歌壶访问、长期变化 |

首发蒙德宁可做十几到二十个真正有生活感的人，也不要做大量统一规格角色。派蒙是唯一“超规格”陪伴角色。


### 12.2 关系成长

阶段可用陌生→认识→熟悉→朋友→亲密朋友→挚友表达，但不必强调数字等级。

关系来自聊天、共同活动、聚餐、事件、帮助、旅行、节庆、礼物、家园访问等。

不要求每日聊天，不衰减；重复送同一礼物收益递减。

角色偏好通过观察、对话和他人信息逐渐得知。

人物事件按上下文条件触发，不用“3心事件”明显UI。

高关系角色可主动邀请、偶尔来访、偶尔帮忙；拒绝不惩罚。


## 13. 探索、地图与世界发现

首发采用多个中型高密度区域，不追求巨型无缝开放世界。

地图知识三态：已知、听说过、未知；地图是被旅行和知识逐渐“走出来”的。

第一次到达强调旅程，发现锚点后重复往返强调便利。

地图开始显示基础地形，玩家发现后增加洞穴、鱼类水域、特殊植物区域、遗迹、观点等知识。

资源图鉴显示已知区域/生态，不显示精确刷新坐标；玩家可自己标记。

宝箱更少但更有语境，奖励图纸、食谱、种子、书籍、地图、材料、收藏等。

谜题可以永久改变世界：修复水轮、开水渠、修桥、开捷径等。

不强调99%探索率；旅行记录逐步显示已知与未知。


### 13.1 危险分级


| 等级 | 定位 |
| --- | --- |
| 安全 | 城市、村庄、农场、主要道路，几乎无敌对 |
| 普通野外 | 稀疏可绕怪物，采集、钓鱼、探索为主 |
| 危险 | 洞穴、遗迹、深林、营地，更多战斗与稀有资源 |
| 高风险 | 深层遗迹、巢穴、极端区域、Boss，少量但有意义 |

危险不仅来自战斗，也可以来自路线、寒冷、热、毒性植物、机关、迷宫和准备压力。


## 14. 战斗与冒险家协会


### 14.1 战斗定位

战斗约占整体体验10–15%，是探索辅助系统，不独立形成长期Build循环。普通战斗应短，怪物通常可绕开；Boss是少量首次探索里程碑，不作为周常材料供应商。


### 14.2 冒险家协会

定位为永久冒险中心：登记、记录、怪物研究、探索记录、长期挑战、冒险商店、Boss记录与危险信息。

不做每日委托/程序化“杀10只史莱姆”任务机。

基础怪物材料可高价购买，避免不喜欢战斗的玩家被强制刷怪；稀有探索/Boss纪念物不可购买。

长期挑战主要是自然累计记录，不应让玩家感觉被迫刷数量。


## 15. 钓鱼、水域与采矿


### 15.1 钓鱼

水体是生态系统而非固定发光钓鱼点；鱼由地区、水体、时间、天气、季节、水层共同决定。

玩家学习栖息规律而不是记坐标。

流程：观察鱼影→选饵→抛竿→咬钩→张力→收线；普通鱼简单，稀有鱼有独特行为。

传奇鱼少量、条件可推理，不做0.01%纯随机。

用途：出售、料理、加工、养殖、展示、赠礼、图鉴。

家园鱼塘可养部分鱼；特殊/传奇鱼保留野外价值。


### 15.2 采矿与洞穴

不做100层每日重置矿洞；采用手工永久洞穴地图+动态资源再生。

表层矿点→浅洞/矿区→深洞/遗迹逐渐增加资源、生态、谜题和危险。

结构进度永久：清除堵塞、修桥、电梯、开门、捷径不会每天重置。

地下也有菌类、鱼、昆虫、遗物、化石、特殊生物和水域。

矿物主要服务工具、建筑、家具、设施和收藏，不作为主要现金打印机。


## 16. 制作、锻造与隐藏科技网络

科技树不作为一张巨大的可见UI树。它是隐藏在图纸、商店、NPC、书籍、材料描述、地区工艺和探索中的知识网络。

便携制作：简单消耗品与小工具；工作台：家具/农场部件；锻造：工具/金属件；加工：板材/布料/玻璃等；厨房：料理；建筑模式：大型设施。

生产链控制在约2–3层，避免工厂模拟复杂度。

图纸来源：商店、NPC、书籍、公会、遗迹、地区工艺、节庆、关系事件、研究。

新材料的描述可以暗示未来用途，但真正未知技术不显示成巨大“???”列表。

技术应避免死锁：任何关键升级都必须存在可达的材料与知识路径。


### 16.1 蒙德技术上限

首发只做到符合蒙德文化的技术深度：木工、风车机械、葡萄种植、酿造、基础养蜂、温带农业、织物、基础玻璃与基础自动灌溉。高级生态技术、精密机械等留给未来地区，避免蒙德包办所有文明风格。


## 17. 教学与知识传播


### 17.1 三层教学


| 层级 | 目的 | 方式 |
| --- | --- | --- |
| 操作教学 | 告诉玩家怎么做 | 首次需要时的极短明确提示 |
| 世界引导 | 告诉玩家可以做什么 | NPC、商店、图纸、物品、环境、书籍、事件 |
| 玩家发现 | 让玩家理解为什么/何时/怎样深入使用 | 实验、观察、长期经验 |


### 17.2 系统引入双轨+兜底

每个重要系统都应有主动入口、自然入口和兜底入口。例如钓鱼：玩家可提前找到钓鱼NPC主动学；约春4–5世界自然介绍；若很久未接触，NPC/派蒙只轻提醒一次。软日期是“世界开始主动展示”，不是硬解锁日期。


### 17.3 永不直接揭晓

稀有鱼精确地点、特殊植物完整条件、NPC最爱物品、隐藏地点、谜题答案、传奇鱼完整条件、特殊动物行为、隐藏食谱、角色事件触发条件等。

游戏提供线索和知识增长，不把秘密直接变成任务箭头。


## 18. 图鉴、旅行记录与收藏


### 18.1 核心原则

图鉴记录知识；尘歌壶保存记忆。

区分“发现过”和“拥有”。不同类别使用不同研究维度，不统一成捕捉数量。

未知知识逐渐出现，不从第一天展示巨大的???完成清单。

研究100%为可选深度，不锁关键战斗或生活能力。

图鉴不仅是终点，还反向提供栖息地、季节、用途和培养知识，帮助玩家生活。


### 18.2 蒙德完整版内容容量（目标区间）


| 类别 | 目标量 |

| 野生植物/花卉 | 50+ |
| 树木 | 20+ |
| 菌类 | 15+ |
| 鱼类 | 30+ |
| 其他水生生物 | 15+ |
| 昆虫/小型生物 | 40+ |
| 鸟类 | 25+ |
| 野生动物 | 20+ |

### 18.3 三层发现结构


| 层级 | 比例建议 | 特点 |
| --- | --- | --- |
| 常见 | 约60% | 正常生活一年大多能遇到 |
| 条件 | 约30% | 特定季节、天气、时间、地点、能力或知识 |
| 秘密 | 约10% | 特殊生态组合、深入探索、人物线索、长期观察；有规律，不靠极低概率折磨玩家 |


### 18.4 个人历史

条目可记录首次发现/采集/种植/捕获日期、最大鱼体型、最高品质、发现地点、天气、共同经历等。照片自动带日期、时间、地点，可进入旅行相册并挂在家中。


## 19. 蒙德生态母版


### 19.1 环境层


| 环境 | 主要内容 |
| --- | --- |
| 平原 | 农作物、草本、小动物、风车、道路生态 |
| 森林 | 木材、菌类、昆虫、鸟类、倒木与隐藏路线 |
| 湖泊/河流 | 淡水鱼、水生植物、蛙类、蜻蜓、未来水上探索 |
| 山地 | 矿物、高山花卉、鹰类、特殊风景 |
| 海岸 | 贝类、海鱼、海鸟、离岸小岛 |
| 城镇 | 慕风蘑菇、鸽鸟、商店、人物、建筑生态 |
| 遗迹/洞穴 | 怪物、矿物、菌类、文物、地下水域 |
| 龙脊雪山 | 寒地植物、冰湖鱼、雪地动物、洞穴、特殊矿物、高山生态 |


### 19.2 代表植物与生态思路

保留甜甜花、薄荷、蒲公英、风车菊、塞西莉亚花、小灯草、钩钩果、落落莓、慕风蘑菇等代表植物，同时补充普通温带草本、浆果、芦苇、水草、睡莲、野葡萄和多类菌物。不同物种至少在栖息环境、季节、天气、行为、用途、生态关系或文化意义中有真实差异。


### 19.3 树木

普通乔木、果树、灌木、特殊树木、倒木、枯木、古树分开。桦、松、杉、橡木、苹果、日落果、野葡萄等既提供资源，也参与生态和景观。果树不鼓励为了木材随意砍伐。


### 19.4 动物与观察

蝴蝶、蛾、蜻蜓、蜜蜂、萤火虫、青蛙等承担天气与水域反馈；鸟类有筑巢、迁徙、觅食等季节行为；狐狸、野兔、野猪、鹿、狼等主要用于观察和世界生命感，而不是全部捕捉。


## 20. 节庆、事件与动态世界

原有限时活动可改造成年度节庆或永久休闲活动，无FOMO。

蒙德风花节可成为春季大型节庆；活动包括音乐、摄影、料理、飞行、小游戏、角色聚集等。

奖励以家具、食谱、照片、纪念品、地方种子/食材为主，不做清空活动商店式任务。

动态世界事件替代无限任务：资源盛放、鱼群、特殊生物、稀有天气、旅行商人、NPC偶遇等。

事件可错过当次但未来重复；不因错过永久失去关键内容。


## 21. 一到五年的长期流程


| 年份 | 主题 | 主要体验 |
| --- | --- | --- |
| 第1年 | 发现 | 认识家园、蒙德、基础系统、四季生态与人物；从“游戏告诉我”过渡到“我自己决定”。 |
| 第2年 | 建立生活 | 家园快速发展，农业/动物/料理/制作进入第二层，玩家形成自己的玩法偏好。 |
| 第3年 | 深入蒙德 | 强化工具、洞穴、雪山、隐藏生态、条件图鉴与旧地图回访成为重点。 |
| 第4年 | 世界留下时间 | NPC工作/生活、商店、道路、生态恢复、来访习惯等出现长期变化。 |
| 第5年 | 归属 | 成熟家园、收藏、关系、生态研究与个人目标为主；可有轻量纪念事件但没有THE END。 |
| 第6年+ | 持续生活 | 季节、天气、市场、生态、人物与玩家自定目标继续循环，不依赖不断解锁新系统。 |


### 21.1 第一年四季

春：高密度但短促地介绍家园、农业、城市、商店、采集、料理、钓鱼、图鉴、矿业、动物和第一次节庆；春后半游戏逐渐“闭嘴”。

夏：第一个真正自由的季节；通过鱼虫、植物、NPC活动和天气变化让玩家理解季节改变世界。

秋：生产成熟、果园、加工、酿造、丰收与市场更活跃，家园明显成形。

冬：普通农业减少但不空档；雪地生态、冰湖鱼、室内生活、加工、手工、人物来访与龙脊雪山价值上升。


### 21.2 第五年纪念

可设计一个极轻的旅行者与派蒙夜间回忆事件，根据玩家真实记录提及第一次收获、远行、人物、家园变化等。第二天照常继续，不作为通关或结局。


## 22. 当前仍需专项完善的问题

体力、睡觉、凌晨、昏迷与失败规则：如何既保留日节奏又不强迫玩家。

旅行与住宿：随时回尘歌壶、旅馆、露营、远行感之间如何共存。

森林/木材完整规则：砍伐、再生、硬木、倒木、家园种树和生态影响。

世界刷新：永久世界、生态再生、动态事件三类的具体刷新节奏。

NPC帮工的访问频率、多人同时来访、角色自身日程与长期变化规则。

物品数量治理：独立物品、标签、变体的判定标准，避免数据库膨胀。

经济后期：成熟玩家的合理长期消费与财富价值。

蒙德核心角色名单与每个角色的内容深度。

蒙德300–500个具体图鉴条目及其季节/天气/地点/用途/研究条件。

隐藏科技网络与所有关键工具/建筑的前置关系检查。


## 23. 下一阶段内容制作建议

当前项目已从“想系统”进入“填内容并验证长期节奏”的阶段。下一步优先产出三份母表：

《蒙德图鉴总表》：逐条列名称、分类、环境、季节、时间、天气、观察/获取方式、用途、可否带回家、深层研究条件。

《蒙德五年生活节奏表》：按年/季列生态变化、节庆、世界变化、人物变化、家园发展窗口与可自然出现的新知识。

《图纸—工具—建筑—知识网络》：标记玩家在哪里第一次知道它、如何主动提前发现、自然介绍时间、材料前置与防死锁路径。

首发目标不是“做完提瓦特”，而是让玩家在蒙德生活五年后仍然觉得：这里还有东西值得看，而这个家确实是我生活出来的。
