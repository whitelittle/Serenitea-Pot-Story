# 提瓦特生活模拟 · 开发总纲

用「千星奇域客户端脚本」做一款**星露谷式的完整生活模拟**，舞台是**整个提瓦特**。

---

## 一、要做什么

**《提瓦特生活模拟》**——玩家在提瓦特生活、经营、探索、成长。

- **完整系统**：种植、畜牧、采集、钓鱼、采矿、战斗、制作、经济、NPC 关系、季节与节庆、图鉴收藏、长期进度……该有的都要有，成体系地做，不是做几个 Demo 拼在一起。
- **整个提瓦特**：蒙德、璃月、稻妻、须弥、枫丹、纳塔、至冬，七个国度都要在规划里，不止蒙德。
- **三条要求**：系统完善、美术优秀、可玩性高。
- **自由度归你**：玩法、区域、系统、内容量、节奏，都可以按需求自行拓展和补全；**工具、脚本、文档只是辅助手段**，是为做游戏服务的，不要为了交工具而交工具。
- **最终成果提交回 GitHub**：<https://github.com/whitelittle/Serenitea-Pot-Story>

## 四、开工前只有一件事必须搞清

**先读 [`平台能力清单.md`](平台能力清单.md)。**

这个平台提供的是**客户端控件**：图片、文本框、网格视窗、容器、动效、Tween、信号……**没有物理、没有寻路、没有瓦片地图对象、没有世界实体、客户端也没有存档接口**。

这**不是给你的玩法设上限**，而是说：你的所有玩法最终都要落成「**用控件当图元 + 每帧改属性 + 需要持久化的交给服务器信号**」。先弄明白这条，再动手设计；否则会做出平台跑不起来的东西。真遇到文档没写的（`UNKNOWN`），自己写个最小验证，别凭印象写 API 名字。
