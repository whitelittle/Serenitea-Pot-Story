# 挑一个目标，手写一个 Lua

每个文件都可单独阅读和改写。模板的目录、命名和注释是给 AI 快速定位能力、解释前提和复用代码的固定抓手；同时按人类阅读标准编写：配置集中在顶部，函数职责清楚，关键前提和停止方式写在文件头附近。先读 [手写教程](../docs/06_新手手写Lua模板.md)，按文件头准备控件，再从配置区开始写。不要求先学五态框架，也不需要把所有模板拼起来。预建控件沿用简中正式名称；所有名称查找从 CONFIG 读取。重命名或区分同类控件时，按 [控件名称与 CONFIG](../docs/08_控件名称与CONFIG配置.md) 修改，或让 Agent 代为同步。

简化标准是“人能看懂、能手改、能解释每一步”：一个文件只练一个主要目标，配置不藏在函数深处，不靠隐式全局或通用框架才能读懂。完整的生命周期、对象存活检查和资源清理仍保留，因为它们决定示例能否安全停用和销毁。

**09–16 是同一组练习**：每个只演示一种能力，独立可读，均为本包根据公开资料抽象改写的教学例子，不依赖外部工程文件。其中借用已有控件的例子（09/11/12/13/14/16）不需要为普通已有实例填写模板索引；10 和 16 的动态创建部分需要你工程的真实索引。16 的随机道具按键和服务器信号都是可选项。

## 动手时记住六件事

1. 用 `GetChild` 找直接子控件、`FindChild` 找相对路径；只有在父级范围内确认唯一时，才把模板索引扫描用于诊断。已有实例优先保留对象引用或使用运行时 `id`。
2. 调用前确认对象存活、字段所属类型和读写性；API 以 [正文](../docs/客户端控件API文档.md) 的完整签名为准。
3. 改配置 → 写一个操作函数 → 接入生命周期或事件。公有函数可在同一脚本直接调用；跨脚本调用另查 `Script:Invoke` 的实例用法。
4. Tween 与逐帧代码不要同时写同一字段；取消用 `Kill(false)`，监听注销使用原回调引用。
5. 停用后怎么恢复要明确：09 从初始状态重播；10 清池后按需创建；11 等下一次显式触发；12 回到 Idle；13 重新绑定输入。销毁时恢复借用状态或释放自有资源。
6. 完成 Lua、API、状态和资源检查后可以继续创作，不强制真机验收；模拟测试不能写成游戏内通过。网格方案还要确认每项事件随回调注册、拖拽预览不拦截光标、刷新后恢复滚动进度。

需要卡牌演出查 [Tween 配方](../docs/03_卡牌Tween演出配方.md)，需要拆分文件查 [多文件练习](multifile/README.md) 的适用前提。

预设按钮的四个模板引用和状态槽位的编辑器步骤见 [预设按钮四态与样式](../docs/10_预设按钮四态与样式.md)。
