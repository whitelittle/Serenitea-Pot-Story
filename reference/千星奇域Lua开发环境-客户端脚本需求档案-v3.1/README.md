# 客户端脚本需求档案

当前分发版本：**v3.1**。本次修订统一按钮结构术语，并补充预设按钮空外观、输入响应与显示证据的防混淆规则；Lua 模板未改动。

可独立复制的 Lua 创作包。AI 从 [AGENT.md](AGENT.md) 开始；新手从 [手写教程](docs/06_新手手写Lua模板.md) 开始。运行代码仍需千星奇域编辑器和自己的工程配置，文档不依赖上一层项目。

## 选一个入口

- **手写 Lua：** [开始之前](docs/00_开始之前.md) → [手写教程](docs/06_新手手写Lua模板.md) → [模板目录](templates/README.md)。一次选一个练习。
- **预设按钮：** 需要编辑器四态、按键样式或点击音效时，才读 [预设按钮四态与样式](docs/10_预设按钮四态与样式.md)，准备四个直接子级“模板引用控件”。
- **组合式按钮（自定义交互）：** 使用 [容器节点 + 内容控件 + 光标检测区域](docs/08_控件名称与CONFIG配置.md#组合式按钮推荐结构)。与预设按钮按结构区分，不按“动态/静态”区分；选型前查看 [按钮术语与防混淆清单](docs/08_控件名称与CONFIG配置.md#按钮术语与防混淆清单)。
- **网格背包/商品列表：** 先读 [网格列表项与 InstantiateClientUI 区别](docs/11_网格列表项与InstantiateClientUI区别.md)，再读 [网格背包动态列表与拖拽配方](docs/16_网格背包动态列表与拖拽配方.md) 和 [模板 16](templates/16_网格背包_动态列表与拖拽.lua)，最后查 API §20；列表项使用 `itemPrefabIndex + RefreshItems`，普通面板和拖拽幽灵才使用 `InstantiateClientUIControl`。
- **学习动画：** [纯文本动画知识](docs/04_视频动画学习笔记.md)、[卡牌 Tween 配方](docs/03_卡牌Tween演出配方.md)、[复刻示例提炼](docs/09_复刻示例提炼.md)。
- **播放做好的动效：** [界面动效与全屏界面动效](docs/12_界面动效与全屏界面动效.md)；编辑器怎么选动效、Lua 怎么播与停。
- **排错：** [typeof 与控件树](docs/13_调试_typeof与控件树.md) 讲清三个最先要用的调试能力。
- **查官方控件详见内容：** [AI 纯文本摘要](docs/15_官方详见页面与图片文字记录.md) 直接回答 12 个官方子页的概念、正式接口类型和编辑器前提；需要看界面时再打开 [官方客户端控件详见图册](guides/官方客户端控件详见图册.md)，其中附 81 张本地官方图片。
- **看原教学画面：** [视频逐页图册](guides/视频逐页图册.md)，含动画视频全部 44 页和控件视频 6 张精选截图；每张有时间、标题与出处。
- **查来源和授权：** [Reference / 致谢](REFERENCES.md)、[CC0 适用范围](LICENSE.md)。

## 文件安排

| 位置 | 用途 |
|---|---|
| `AGENT.md` | AI 的规则、按需索引与回复要求 |
| `.agent-ignore.md` | 给读取者的读取边界说明；不宣称所有工具都会自动识别 |
| `prompts/` | 生命周期、输入、动效、交付等场景规则 |
| `docs/` | 文本知识、API 与官方指南离线快照、索引 |
| `templates/01–08` | 较完整的接入与基础能力例子 |
| `templates/09–16` | 同一组练习：逐帧、复用、转场、状态、输入、动效、预设按钮、网格背包 |
| `docs/11`、`docs/12`、`docs/13`、`docs/14`、`docs/15`、`docs/16` | 网格边界、界面动效与全屏动效、typeof 与控件树调试、按键提示、官方详见 AI 摘要、网格背包动态列表与拖拽配方 |
| `templates/multifile/` | 可选拆分教学，先读运行前提 |
| `guides/` | 人类图册、官方控件图册与截图清单，不作为 AI 默认检索正文 |
| `REFERENCES.md` | 官方、社区、样本和观察来源；免责与侵删 |
| `LICENSE.md`、`licenses/CC0-1.0.txt` | 原创部分的 CC0 声明及标准文本 |

让 AI 先读 AGENT，再描述效果和希望生成的文件。已有配置直接使用；只对影响下一步的缺失信息提问。控件和图片编号要从自己的编辑器或资产清单取得。

创建控件后可继续完成玩法，不强制先真机验收。AI 应先做 API、Lua、状态与资源检查，明确区分模拟检查和客户端运行观察。
