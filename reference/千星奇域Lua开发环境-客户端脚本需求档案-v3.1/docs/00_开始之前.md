# 开始之前

简中预建控件的正式名称及改名时的配置位置，见 [控件名称与 CONFIG](08_控件名称与CONFIG配置.md)。

## 脚本、控件和图片是什么关系

```text
本地 .lua 文件 → 脚本映射 → 挂到客户端控件
                                  ↓ script.object
                             实际宿主对象
                                  ↓ 查找或创建
                             图片/文字等实例
                                  ↓ Tween
                             随时间改变的画面
```

映射是编辑器对本地文件的登记；挂载是让哪个控件运行这个脚本；模板是可以用来生成实例的控件设计；图片资产只是图片内容。这四件事要分开。

## 第一次做

1. 按 [开工交接](../prompts/20_开工交接.md) 准备客户端控件容器、进入画布。
2. 从 [模板目录](../templates/README.md) 选择一个 Lua 文件，保存为你自己的入口文件。保留 `.lua` 扩展名。
3. 根据文件顶部注释，在编辑器创建所需控件或保存模板；把真实名称、索引填到配置区。
4. 在客户端脚本资源管理器建立脚本映射，再在所需节点的脚本页签挂上它。常用宿主是容器节点；其他客户端控件也可挂脚本，依示例前提选择。
5. 阅读 [手写教程](06_新手手写Lua模板.md)，理解初始化、操作函数、停止和销毁的分工。

你可以先完成代码与知识检查，再决定什么时候试玩。想看效果时先保存本地文件，再在编辑器保存并试玩；没有运行日志时不能声称已观察成功。

## 新建与借用

- 新建：用存为模板的父节点索引调用 `game.InstantiateClientUIControl(index, parent)`；由你的脚本销毁新实例。
- 借用：从 `script.object` 出发，用 `GetChild` / `FindChild` / `GetChildren` 在明确层级找已有控件；不要销毁借用节点。
- 官方指南规定主屏画布节点与模板内部子节点不支持直接实例化；不是每个有索引的控件都能创建副本。
- 名称查找有作用域；同一模板的多个实例可以有相同 `prefabIndex`。匹配索引不能替代唯一实例引用。
- 网格视窗是单独的创建路径：设置 `itemPrefabIndex` 后调用 `RefreshItems`，由网格创建或复用列表项；不要用 `InstantiateClientUIControl` 代替网格列表项。完整边界见 [网格列表项与 InstantiateClientUI 区别](11_网格列表项与InstantiateClientUI区别.md)。
