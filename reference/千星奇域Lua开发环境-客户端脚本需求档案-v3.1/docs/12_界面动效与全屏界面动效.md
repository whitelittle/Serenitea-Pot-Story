# 界面动效与全屏界面动效

来源编号：`REF-EDITOR-ANIM`（创作者提供的编辑器截图）。这份说明处理两个控件的 Lua 用法：`界面动效` 与 `全屏界面动效`。

## 1. 先分清职责

| 谁 | 负责什么 |
|---|---|
| 编辑器 | 配置动效本身：在【选择动效】里挑一个动效资源，设置播放参数 |
| Lua | 只负责**播放、停止、切音效开关**，以及把动效放在哪里 |

**Lua 不能创建动效，也不能编辑动效内容。** 截图里那个动效列表（`视线特效1` … `视线特效21` 这类）是编辑器资产；脚本只能按已配置的动效 ID 播放。

## 2. 编辑器里怎么配（按截图）

以【全屏界面动效】为例，界面动效同理：

1. 在【界面控件组库】选【客户端控件模板】或从容器画布进入，添加【全屏界面动效】。
2. 右侧 inspector 的【动效设置】里点【选择动效】，在弹出面板中选择需要的特效——面板里按编号列出当前工程可用的动效（截图示例是 `视线特效1`～`视线特效21`，各自带索引号）。
3. 选中后，右侧 inspector 的【选择动效】一行会显示所选动效的名称与索引号，这就是运行时用的动效 ID。
4. 需要时继续配置同一面板里的位置、尺寸、缩放、锚点、最小/最大锚点与中心点；这些按你的布局需要设。
5. 若动效要跟位置走，面板里的【插点设置】用于配置动效绑定的位置点；按需求选择。
6. 【是否播放特效】决定这层动效是否启用；【手柄导航】/【可被手柄摇杆导航选中】按是否需要手柄选中来设。
7. 勾选【开始播放】之类的播放入口后，保存模板或控件组。

界面动效额外有两项：

- 【动效层级】：`Enum.UIAnimationLayer.AboveAllControls`（所有控件之上）或 `BelowAllControls`（所有控件之下）。
- 【是否播放动效音效】：对应字段 `playSoundEffect`。

## 3. Lua 侧能用什么

| 控件 | 可写字段 | 可调用方法 |
|---|---|---|
| `ClientUIAnimationControl`（界面动效） | `animationId`、`playSoundEffect`、`layer` | `PlayAnimation()`、`StopAnimation()` |
| `ClientUIFullscreenAnimationControl`（全屏界面动效） | `animationId`、`playSoundEffect` | 无专用方法；播放走编辑器配置的播放入口 |

接口以 [客户端控件API文档](客户端控件API文档.md) §22、§23 为准。

## 4. 一个最小用法

```lua
-- 前提：宿主容器节点下有一个“界面动效”控件，且编辑器里已选好动效、设好播放入口。
local CONFIG = {
    ANIM_NAME = "界面动效",     -- 改成你工程里的实际名称
}

local host, anim = nil, nil

local function prepare()
    host = script.object
    if host == nil or not host.alive then return false end

    local candidate = host:GetChild(CONFIG.ANIM_NAME)
    if candidate == nil or not candidate.alive then
        printerr("[动效] 找不到控件：" .. tostring(CONFIG.ANIM_NAME))
        return false
    end
    -- 播放/停止不是所有 subtype 都实现，先取方法再判断
    local ok, fn = pcall(function() return candidate.PlayAnimation end)
    if not ok or type(fn) ~= "function" then
        printerr("[动效] 该控件没有 PlayAnimation，确认它是不是“界面动效”")
        return false
    end
    anim = candidate
    return true
end

local function play()
    if anim == nil or not anim.alive then return end
    local ok, err = pcall(function() anim:PlayAnimation() end)
    if not ok then printerr("[动效] 播放失败：" .. tostring(err)) end
end

local function stop()
    if anim == nil or not anim.alive then return end
    pcall(function() anim:StopAnimation() end)
end

function OnStart()
    if prepare() then play() end
end

function OnDisable()
    stop()
end

function OnDestroy()
    stop()
    anim, host = nil, nil
end
```

可直接拷的完整骨架见 [15 界面动效](../templates/15_界面动效_播放与停止.lua)。

## 5. 注意

- **不要用 Lua 猜动效 ID。** 列表里的编号由当前工程产生，本包不给出示例数值；要改 `animationId` 就先在编辑器里选中动效，读 inspector 上显示的那个编号。
- **`StopAnimation()` 的收尾状态**（停止后停在哪一帧）API 没有声明，需要固定收尾时自己用别的方式兜住，不要假设它会回到初始画面。
- **动效和 Tween 是两条路**：要求"跟着数值走、可随时改目标"的用 Tween；要求"播一段做好的特效"的用动效控件。两者同时改同一控件时，注意字段归属。
- 全屏界面动效覆盖在界面之上，层级与是否点击穿透由它自己的配置决定；不要让它在需要点击的区域常驻遮挡。
