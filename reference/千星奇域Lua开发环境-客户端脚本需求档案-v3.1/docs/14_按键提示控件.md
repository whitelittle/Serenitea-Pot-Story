# 按键提示控件

来源编号：`REF-EDITOR-NAMES`。`按键提示`是纯显示控件，用来在手柄和键鼠上显示对应的快捷键图标。

## 1. 它只影响画面

**按键提示仅影响视觉，不影响响应事件。** 按键怎么响应由 `AddKeyEventListener` 那套监听决定，和这个控件无关。所以：

> 出处：这句来自官方《千星沙箱客户端脚本使用指南》早期整理稿的「详细控件&脚本功能介绍 → 按键提示」一节。随包副本 `千星沙箱客户端脚本使用指南.md` 是官方页面正文同步稿，只收录到「封装的提示信息控件，可配置 PC、键鼠和手柄端的快捷键」，**没有包含这句结论**；API 正文 §21 只声明 `keyboardKeyCode` 与 `controllerKeyCode` 两个字段。按现有材料记为 `provided_unverified`，实机确认后升级。

- 不要指望"加了按键提示，按键就能用了"；
- 也不要为了响应按键去配置按键提示。

## 2. 能用什么

| 字段 | 类型 | 访问 | 说明 |
|---|---|---|---|
| `keyboardKeyCode` | `KeyboardKeyCode` | 读写 | 键鼠按键枚举值 |
| `controllerKeyCode` | `ControllerKeyCode` | 读写 | 手柄按键枚举值 |

接口以 [客户端控件API文档](客户端控件API文档.md) §21 为准。枚举值分别在 §26(1) `Enum.KeyboardKeyCode` 与 §26(2) `Enum.ControllerKeyCode`。

## 3. 一个最小用法

```lua
local CONFIG = {
    HINT_NAME = "按键提示",     -- 改成你工程里的实际名称
}

function OnStart()
    local host = script.object
    if host == nil or not host.alive then return end

    local hint = host:GetChild(CONFIG.HINT_NAME)
    if hint == nil or not hint.alive then
        printerr("[按键提示] 找不到控件：" .. tostring(CONFIG.HINT_NAME))
        return
    end

    -- 按当前玩法要提示的动作设置两套键位；枚举从文档逐字复制
    local ok1 = pcall(function()
        hint.keyboardKeyCode = Enum.KeyboardKeyCode.InteractKey      -- F
    end)
    local ok2 = pcall(function()
        hint.controllerKeyCode = Enum.ControllerKeyCode.InteractKey  -- X
    end)
    if not ok1 or not ok2 then
        printerr("[按键提示] 写入按键枚举失败，确认字段属于这个控件")
    end
end
```

## 4. 注意

- **两套键位分别设**：`keyboardKeyCode` 与 `controllerKeyCode` 是两组枚举，不要互相赋值。
- **按设备切换显示不是自动的**：控件会按当前设备显示对应的那一套，但"当前设备是什么"由编辑器/运行时判定；Lua 侧需要自己判断设备时用 `game.GetDevice()`（见 [输入与导航](../prompts/38_输入.md)）。
- **枚举不要拼接猜名字**：`InteractKey`、`JumpKey`、`CharacterSkill1Key` 这类值从 §26 逐字抄。
- **名称查找有作用域**：`GetChild` 只查直接子级；同名控件多的时候，先给它们不同名称再写 CONFIG。
- **它是显示层**：改键位不改玩法逻辑；玩法逻辑里判断按键仍然走监听回调。
