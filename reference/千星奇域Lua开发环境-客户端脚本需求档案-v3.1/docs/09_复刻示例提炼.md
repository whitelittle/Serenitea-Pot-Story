## 证据如何记录

外部关卡只作为公开结构线索，不在本包记录其运行状态。接口经本包 API 正文核对记为 `K1 / documented`；本包新增的设计记为 `K5 / inferred`；语法与代码检查用 `K2 / static_checked`。本页的方案与模板保持独立。

样本内附带的 `Lua_API.lua` 是随档快照，不能覆盖本包 API：它写 `runtimeId`，实际样本又使用 `id`，应记录冲突并按本包定义核对：运行时 ID 一律以 API 文档 `ClientUIBaseControl` 的 `id` 字段为准（`客户端控件API文档.md` §13），不采用 `runtimeId` 等样本写法。`require` 路径只能作为样本线索；本包未确认宿主模块解析规则。

本样本是补充参考之一。下表是便于手写的练习，不要求照搬原作品或本包模板；静态切换、Tween、逐帧、独立创建或复用等方式按目标与规模选择。

## 控件先准备好，再写一个函数

- 09：按 `CONFIG.FRAME_GROUP_PATH` 准备帧总组，在 `CONFIG.STATES` 填状态组路径和有序帧名称。`FindChild(path)` 取得预建帧；`PlayFrameState("action")` 播放一轮后回到 idle；`StopFrameAnimation()` 停止。
- 12：宿主下准备两个状态根，在 `CONFIG.IDLE_NAME`、`CONFIG.ACTION_NAME` 填实际名称。`GetChild(name)` 取得引用；调用 `PlayAction()` 或按 E；动作未结束时忽略重复触发。
- 11：准备两张遮罩图片和一个抖动画面容器，在 `CONFIG.TOP_MASK_NAME`、`BOTTOM_MASK_NAME`、`WORLD_SHAKE_NAME` 填实际名称。遮罩在编辑器中摆在合拢位置；修改 `OPEN_DISTANCE` 使打开后离开显示区域。`PlayTransition()` / `PlayShake()` 触发，`StopPresentation()` 取消。抖动容器是 UI 根，不是真实相机接口。
- 10：在本项目准备可动态创建的图片模板，填写 `IMAGE_PREFAB_INDEX`；`SpawnEffect(x, y, lifetime)` 触发，寿命结束归还池。停用时销毁池，再启用按需创建。
- 13：容器下准备“图片”“光标检测区域”；名称集中在 `CONFIG.IMAGE_NAME`、`CURSOR_AREA_NAME`。按文件头设置可见性、激活和射线检测；坐标前提不满足时停止移动。

各例独立使用；不用先照抄原工程，也不需要全部挂在同一宿主。默认名称沿用简中编辑器正式名称；多个同类控件按实际工程区分名字，名称与路径在 CONFIG 中集中填写，见 [控件名称与 CONFIG](08_控件名称与CONFIG配置.md)。

## 迁移时保留的约束

1. **所有权明确。** 09/11/12/13 借用控件，销毁脚本时恢复其负责的原状态，不销毁控件；10 只销毁自己创建的图片。
2. **一个字段一个写入者。** 位移根与抖动根分开；取消旧动画后再创建新动画，旧回调凭令牌失效。
3. **时间有界。** 逐帧使用有效 `dt`；卡顿不执行无界追帧；一次性状态明确结束条件。
4. **序列只用已声明能力。** `Append`/`Join` 的参数按本包文档是 Tween；样本里嵌套 Sequence 的写法不据此推广。
5. **编号和接口不搬运。** 不复制 prefab、imageId、音频和关卡数值；`.parent` 是字段，不发明 `SetParent`。`showCursor` 属于容器，不是光标检测区域字段。
6. **坐标不猜。** 屏幕 UI 拖拽差值不普遍等于父级局部位移。13 限制相关层级单位缩放、零旋转；不满足时拒绝执行，不用试玩猜换算。

建议学习顺序：单控件 Tween → 12 两个状态 → 09 逐帧 → 11 时间线 → 按需要选 13 输入或 10 复用。按 [API 阅读规则](01_API阅读与防混淆.md) 和 [知识层级](05_知识层级验证与Debug.md) 自检即可继续创作；真机观察不作为交付前置任务。
