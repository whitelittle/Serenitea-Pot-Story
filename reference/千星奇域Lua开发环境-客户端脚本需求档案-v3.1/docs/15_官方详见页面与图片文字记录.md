# 官方客户端控件“详见”页：AI 查询摘要

本文件是给 AI 和新手查阅的纯文本摘要，不要求打开网页、逐张读图或读取图片地址。官方页面的 12 个控件详见页统一记为 `REF-GUIDE-DETAILS`；来源和权利边界见 [`REFERENCES.md`](../REFERENCES.md)。需要核对编辑器画面时，再打开人类图册 [`guides/官方客户端控件详见图册.md`](../guides/官方客户端控件详见图册.md)。

## 主页面的共同前提

- 服务器控件由服务器节点图控制；客户端控件由客户端脚本控制，二者不是同一类对象。
- 客户端控件必须位于客户端控件容器内；容器激活且可见时，控件和挂载脚本才运行。容器隐藏或销毁会影响子控件。
- 编辑器入口是【界面控件组管理 → 界面控件组库 → 客户端控件模板】，或【界面布局 → 添加界面控件 → 客户端控件容器 → 画布设置 → 前往编辑】。
- 脚本映射要在千星沙箱中建立并挂载到客户端控件；本地 Lua 文件名、控件模板索引和运行时 ID 不能互换。
- `ServerSignal`、自定义变量、按键监听和手柄导航都要按 API 正文的签名回查；本摘要不扩展 API。

## 控件摘要

### 1. 客户端控件容器（`mhlz2lrly3dq`）

- **用途：** 为客户端控件提供运行画布和脚本运行环境。
- **编辑器动作：** 添加“客户端控件容器”模板，选中后从“画布设置 → 前往编辑”进入控件画布，再添加控件。
- **脚本判断：** 容器未激活、不可见或已销毁时，不要把子控件未出现误判成 API 失败。
- **回查：** 容器运行前提见官方指南和 API 的 `GetClientUIRoots`、`ClientUIContainerControl`。

### 2. 容器节点控件（`mh3qqq9xc102`）

- **用途：** 组织子控件；可控制常驻光标、按键穿透、光标事件穿透和手柄导航隔离。
- **正式接口类型：** `ClientUIContainerControl`。
- **关键字段：** `showCursor`、`isolateNavigation`、`disableKeyEventPassthrough`、`disableCursorEventPassthrough`。
- **回查：** 光标事件要先确认容器 `showCursor = true`；字段读写性以 API §24 为准。

### 3. 文本框控件（`mhnltrr3g966`）

- **用途：** 显示单段文本，支持编辑器文本、自定义变量和对齐。
- **正式接口类型：** `ClientUITextBoxControl`。
- **编辑器要点：** 背景可选无或黑色半透明；可配置字号、文本、水平/垂直对齐。官方示例变量格式为 `{1:p4.测试2}`，其中类型为 `1`，`p1`–`p8` 表示玩家，`lv` 表示关卡实体，`ps` 表示玩家自身实体。
- **回查：** 脚本修改使用 `text`、字号、颜色等 API 明确的读写字段，不把变量展示语法当作 Lua 表达式。

### 4. 文本视窗控件（`mhv38jig94kk`）

- **用途：** 显示可滚动的多行文本。
- **正式接口类型：** `ClientUITextWindowControl`。
- **编辑器要点：** 先开启“是否可滚动”，再决定是否显示滚动条；其他文本设置与文本框相近。
- **回查：** `interactable`、`showScrollBar`、`text` 和对齐字段以 API §16 为准。

### 5. 图片控件（`mh2oih9jou22`）

- **用途：** 显示静态或动态图片，并提供颜色、遮罩、羽化和进度填充。
- **正式接口类型：** `ClientUIImageControl`。
- **编辑器要点：** 图片源包括静态引用、道具、装备、技能、单位状态、阵营和货币等；图片类型包括基础、拉伸、三宫格和九宫格。遮罩可裁切子图、反转区域、设置像素/百分比羽化，并支持水平、垂直、90/180/360 度填充。
- **回查：** 图片修改使用 `SetImage`；`imageSource`、`imageId` 是只读配对；填充方向和枚举不能混用。具体字段见 API §14。

### 6. 界面动效控件（`mh2iyk9fa4gy`）

- **用途：** 在界面布局中播放已配置的界面动效资产。
- **正式接口类型：** `ClientUIAnimationControl`。
- **编辑器要点：** 配置动效资产、是否播放自带音效和层级（所有控件之上/之下）；编辑器可开启常驻预览。
- **回查：** Lua 侧用 `animationId`、`playSoundEffect`、`layer`，播放/停止用 `PlayAnimation()`、`StopAnimation()`；不要把编辑器预览当成运行时播放结果。

### 7. 全屏界面动效控件（`mhbn4i09l5ns`）

- **用途：** 覆盖整个屏幕的氛围或转场动效。
- **正式接口类型：** `ClientUIFullscreenAnimationControl`。
- **编辑器要点：** 默认位于所有层级最下方且层级不可改；配置动效资产和音效开关。
- **回查：** 它与普通界面动效是不同控件类型；不要把 `UIAnimationLayer` 或普通界面动效字段套过来。

### 8. 预设按钮控件（`mhdbkf04v6y8`）

- **用途：** 由编辑器管理默认、悬停、按下、不可用四种状态的按钮。
- **正式接口类型：** `ClientUIPresetButtonControl`。
- **编辑器要点：** 状态外观来自各状态节点下配置的子控件；另有光标射线检测、可用开关、按下音效和手柄导航。
- **回查：** 需要四态和点击音效时才选它；动态换图按钮优先采用“容器节点 + 图片/文本框 + 光标检测区域”。脚本事件方法见 API §17。

### 9. 按键提示控件（`mh265urgupye`）

- **用途：** 根据输入设备显示快捷键提示。
- **正式接口类型：** `ClientUIKeyHintControl`。
- **编辑器要点：** 配置键鼠与手柄按键显示，并设置手柄导航目标。
- **回查：** 键码使用 API 的 `KeyboardKeyCode`、`ControllerKeyCode` 枚举；不要用普通文本模拟按键提示的设备适配。

### 10. 光标检测区域控件（`mhd4fxr5v6la`）

- **用途：** 接收区域内的光标事件，常与图片和文本框组成动态按钮或列表项。
- **正式接口类型：** `ClientUICursorEventAreaControl`。
- **编辑器要点：** 可开启范围常驻预览和“可被光标射线检测”，并配置手柄导航。
- **回查：** 监听使用 `AddCursorEventListener`；事件为 `CursorDown`、`CursorUp`、`CursorEnter`、`CursorExit`、`CursorDrag`、`CursorBeginDrag`、`CursorEndDrag`、`CursorClick`。动态列表的每个复用项都要单独绑定并在清理时移除。

### 11. 网格视窗（`mhfkrr0i7gds`）

- **用途：** 背包、商品和滚动列表；运行时复用可见列表项。
- **正式接口类型：** `ClientUIGridScrollerControl`。
- **编辑器要点：** 配置射线检测、滚动、滚动条、方向、项大小、边距、自动换行/固定布局、列表项模板和手柄导航。
- **回查：** 先写 `itemPrefabIndex`，再调用 `RefreshItems(itemCount, callback)`；回调中的控件由网格管理，用 `GetItemIndex` 获取运行时索引。普通拖拽幽灵才使用 `game.InstantiateClientUIControl`。完整可操作配方见 [`docs/16_网格背包动态列表与拖拽配方.md`](16_网格背包动态列表与拖拽配方.md)。

### 12. 模板引用控件（`mhucb6reudwm`）

- **用途：** 在编辑器中引用另存的客户端控件模板，并在运行时保持被引用模板的表现。
- **正式接口类型：** `ClientUIReferenceControl`。
- **编辑器要点：** 配置“引用控件模板”和手柄导航；引用的是模板身份，不是运行时控件 ID。
- **回查：** 模板引用索引 `referencedPrefabIndex` 与普通 `prefabIndex`、运行时 `id` 分开记录；需要动态复制时回查 API 和 [预设按钮四态](10_预设按钮四态与样式.md)。

## AI 查询规则

1. 问“官方页面讲了什么”时，从本文件回答概念、正式控件名、接口类型和编辑器前提。
2. 问“字段或方法怎么写”时，转到 [`客户端控件API文档.md`](客户端控件API文档.md) 的对应章节；本摘要不替代签名、参数、返回值和读写性。
3. 问“图片里某个开关在哪”时，才打开 [`guides/官方客户端控件详见图册.md`](../guides/官方客户端控件详见图册.md)；图片是人类核对材料，不是 API 事实的唯一来源。
4. 任何官方页面截图、视频画面或外部样本只提供 `video_observed`/`provided_unverified` 级别证据；不能把示例索引、资产 ID 或视觉结果推广成当前工程默认值。
