# 本包的读取边界

这是给读取者的说明文件，不宣称所有工具会自动识别 `.agent-ignore.md`。

- 用户任务与本包无关时，不默认加载整包。
- 用户指定本包时，从 [AGENT.md](AGENT.md) 开始；只读当前需求相关的知识册和模板。
- `AGENT.md` 是本包实际入口；不假设某个工具一定会自动读取它，必要时由用户明确指定路径。
- 模板与视频不是 API 权威，冲突时回查包内 API 正文。
- `guides/` 是人类图册；技术检索默认只读纯文本知识，除非用户明确要求查看画面。来源和授权按需要查根目录 REFERENCES.md / LICENSE.md。
