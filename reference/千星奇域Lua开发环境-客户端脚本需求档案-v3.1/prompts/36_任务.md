# 一次性任务与重复任务

API 正文没有通用定时器接口。不要编造 `setTimeout`、`Wait` 或 `coroutine` 用法。

- 动画结束后做事：保存 Tween，使用完成回调；回调只改变当前有效演出的本地表现。
- 动画里的等待：Sequence `AppendInterval(seconds)` 后接回调。
- 与动画无关的倒计时：在一个 Update 回调累加 `dt`，达到时长置 done 后执行一次，随即关逐帧。
- 重复逻辑：累加器保留余数。是否补执行掉帧期间漏掉的次数由需求决定；设置补执行上限，不能无界 `while` 导致卡死。
- 循环演出：两端位姿显式写出；要可暂停、取消和复位。不要把未知循环复位语义作为正确性的前提。

单次/重复任务都要有有效代号或状态守卫；关闭后旧回调不生效。教学例子见 [模板目录](../templates/README.md)。
