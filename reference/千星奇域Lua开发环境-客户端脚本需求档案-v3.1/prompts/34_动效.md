# 动效规则与选型

教学见 [视频动画笔记](../docs/04_视频动画学习笔记.md)，卡牌配方见 [卡牌 Tween 演出](../docs/03_卡牌Tween演出配方.md)。函数事实回查 API §7、§8、§11，以及目标控件类和基类。

可选择 Tween、逐帧帧图、状态切换、手动插值或已有动效资源，按表现与生命周期需要决定。以下规则专门约束采用 Tween 的方案。

## 采用 Tween 时的编写顺序

1. 指定对象与父级，选定要变化的文档 `Tweenable` 字段。
2. 写起点、终点、秒数、缓动、触发/取消方式；明确相对增量还是绝对目标。
3. 先取消同字段旧演出、设起点，再 `game.Tween`，设置选项，最后 `Play()`。
4. 保存句柄；结束/停用/销毁有对应收口，回调检查当前状态和对象存活。

## 编排选择

| 关系 | 写法 |
|---|---|
| 同一个对象、相同时间和缓动 | 一个 Tween 的目标表写多个字段 |
| 先后 | Sequence `Append` |
| 同一步并行，不同对象/时长/缓动 | 先 `Append`，再 `Join`；该步取最晚结束时间 |
| 时间线上指定起点 | `Insert(time, tween)`；单位秒 |
| 等待、离散更换文本/图片 | `AppendInterval`、`AppendCallback` 或 `InsertCallback` |

序列子 Tween 不单独播放，整个序列只调用一次 `Play()`。相同属性的下一段起值捕获时机未写明时，避免预创建多段依赖中间值的 Tween；在前段完成后新建后段，或者显式控制该段起点。

循环不等于自动往返。呼吸效果明确写放大和缩小两段；不要假定负数循环会累加角度、自动复位或采用某种 Yoyo 方式。常驻循环不得依赖最终完成回调推进玩法。

图片淡出用 `imageColor` 的 alpha；没有通用 `control.alpha` 或容器颜色 API。`active/visible/imageId` 为只读字段，分别使用 `SetActive/SetVisible/SetImage`；`text` 可赋值但不可 Tween。

`Kill(false)` 取消，`Kill(true)` 涉及完成和回调；清理默认前者。后者不是随意的“清理快捷方式”。逐帧跟随与 Tween 不得同时写同一位置。

缓动、时长是本包设计参数，不是官方规定。回弹可能越界，默认保守缓动；布局公式、旋转正方向不能凭其他引擎经验宣称已知。
