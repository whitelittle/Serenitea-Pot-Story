# 选择骨架

可从 [模板目录](../templates/README.md) 选一个相关例子，也可按 [手写教程](../docs/06_新手手写Lua模板.md) 从小函数开始写。模板、视频和 OOO 都是可选补充参考，不限定实现方式，不把所有例子合并成一个框架；本包独立使用时不需要 OOO 或其他外部工程。

- 教学示例不强制五态状态机、路径归一化框架、通用资源栈。
- 只保留当前功能必要的配置；每项注释写用途、单位、真实值怎么取得。
- 未填写 ID 必须安全停止或明确禁用该可选能力，不能悄悄采用其他工程编号。
- 模板是代码线索，首次使用或 API 版本改变仍需回查正文。
- 多文件仅供进阶，先读其模块寻址限制。新手优先选择易读的单文件；确有独立职责时再按需拆分。
