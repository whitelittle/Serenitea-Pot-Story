# 逐帧与调试

`script:EnableUpdate(boolean)` 是 API。

| 需求 | 时间来源 |
|---|---|
| 一次位移、入场序列、呼吸动画 | 通常优先 Tween / TweenSequence；纯 Tween 不额外开逐帧，需要跟随/自定义插值时可按需选逐帧 |
| 点击、按键触发操作 | 事件回调；单次触发不要求空的 Up 回调 |
| 持续按键移动、摇杆读取 | `OnUpdate(dt)`，速度乘 `dt` |
| 跟关卡时停的界面动效、玩法 | `OnLevelUpdate(dt)` |
| 独立的一次延时/重复逻辑 | 见 [任务](36_任务.md)，只选一种时间来源 |

`OnUpdate` 不受关卡时停影响，`OnLevelUpdate` 受。文档未声明 Tween 如何受关卡时停影响，不据此推断；需要精确同步时自己管理暂停/继续。

`dt` 先检查 number、有限、正值。停用时关闭逐帧，恢复时只在确有需求时开启；不要在逐帧中重复建 Tween、找整棵控件树或注册监听。

完整 [Debug 流程](../docs/05_知识层级验证与Debug.md)：先查现有脚本与文档，再按加载→挂载→实例→字段→动画→清理排查。用户已有日志优先利用；探针可选且可关闭，不把“请真机验证”作为每轮结束语。
