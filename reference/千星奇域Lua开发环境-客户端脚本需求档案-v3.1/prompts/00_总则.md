# 总则

先读 [AGENT.md](../AGENT.md)，再按任务进入分册。本文件不再重复全套规范。

1. API 标识必须来自 [API 正文](../docs/客户端控件API文档.md)，用法回查 [阅读规则](../docs/01_API阅读与防混淆.md)。
2. 已提供的输入直接复用；缺失信息只阻塞依赖它的部分，教学和独立逻辑继续完成。
3. 保持改动范围，不把上一层完整工程搬进本包。
4. 每个资源只有一个拥有者，清理覆盖停用、失败、销毁；借用控件不销毁。
5. 静态检查、模拟运行和真机观察分别记录，见 [知识层级](../docs/05_知识层级验证与Debug.md)。不强制创作者逐项试玩。
6. 交付前按 [反查清单](90_交付前反查.md) 检查，简洁回报结果。
