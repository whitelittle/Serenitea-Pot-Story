# 开工交接

先分清任务：审查提示词、学习 Lua 或设计演出无需索取工程 ID；接入正式工程时才核对挂载与资源。已有值可从用户提供的配置读取，不重复问。

## 接入时确认什么

| 信息 | 原因 | 获取方式 |
|---|---|---|
| 实际挂载脚本名 | 防止编辑与挂载的不是同一文件 | 容器画布中选挂载节点，查看脚本页签 |
| 宿主节点的控件模板索引（需身份核验时选填） | 可与 `script.object.prefabIndex` 核对；按实际名称/路径定位时不强制索取 | 在画布选中该客户端节点，读取控件模板索引 |
| 要创建的模板索引，或已有控件的名称/路径 | 区分新建实例与借用实例 | 存为模板的父节点取模板索引；已有子控件取层级信息 |
| 图片来源和图片 ID | 指定内容而非控件身份 | 见 [资产获取规则](../docs/02_图片资产ID索引.md) |

缺少信息时给一句用途和一个获取方法，通常不超过三问。不把时长、缓动、文件结构等常规决定全部交给新手；采用清晰默认值并说明可改。

## 详细做法：怎么把两个值拿到手

下面按编辑器实际操作顺序写。索引读法见 [API 阅读与防混淆](../docs/01_API阅读与防混淆.md) §4 的对照表。

**一、容器节点索引（挂载用）**

1. 【界面控件组管理】→【界面布局】里新增或选一个【客户端控件容器】；工程已有就复用，不重复建。
2. 选中这个容器，在右侧 inspector 的【画布设置】里点【前往编辑】，打开容器。
3. 容器里预设会有一个父节点，那就是**容器节点**。选中它。
4. 读它的**容器索引**（一串数字）。这就是要交接的值。
5. 顺带在它的【脚本】页签里确认脚本已经挂上；挂载名就是要交接的第二个值。

容器节点是单独的控件类型，不是普通模板。它只用于挂载与交接，**不要**把它当控件模板索引传给 `game.InstantiateClientUIControl`。

**二、控件模板索引（要创建模板实例或核对模板身份时）**

1. 【界面控件组管理】→【界面控件组库】→【客户端控件模板】。
2. 新建控件并另存模板，或点开已有模板，进入【界面控件组详细】。
3. 右侧 inspector 面板里，**控件名字下方**显示该控件的**控件索引**。
4. 这就是 `controlPrefabIndex`（控件模板索引），`game.InstantiateClientUIControl(controlPrefabIndex, parent)` 收的是它。已有控件不按这个数字通用查找，优先用名称、路径、创建返回值或运行时 `id`。
5. 只有存为模板的父节点能被动态创建；主屏画布里的节点、模板内部的子节点都不行，见 [官方指南](../docs/千星沙箱客户端脚本使用指南.md)。

**三、图片 ID（需要显示图片时）**

在容器或模板里选中目标图片控件，从属性面板复制来源与 `imageId`（图片 ID）两个值；规则见 [图片资产 ID 索引](../docs/02_图片资产ID索引.md)。

**四、脚本没生效时先查这两条**

- 只在本地建了 `.lua`、没在【客户端脚本资源管理器】里建脚本映射的，试玩时不会被上传。
- 改完脚本要先存本地文件，再在千星沙箱里保存并试玩。

上面四条里，控件类型、字段名和接口签名是 `K1 / documented`；「选中容器节点读容器索引」「控件名字下方读控件索引」这两条读法是创作者确认的编辑器界面事实，记为 `K3 / user_confirmed`。


可先完成带明确未填配置的文件和自检，不要求创作者先跑一张测试界面再继续创作。

以上是常见根容器流程；官方指南允许给客户端控件挂脚本，不应说“所有脚本只能挂容器节点”。本包各模板的挂载前提以文件注释为准。
