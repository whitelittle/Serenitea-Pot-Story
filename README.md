# 尘歌壶物语 · Serenitea Pot Story

「千星奇域」Lua 游戏项目的**需求、参考资料与开发指导**仓库。

当前目标：用千星奇域「客户端脚本 + 客户端控件」做一个**系统完整的星露谷类农场生活模拟**。原「提瓦特生活模拟游戏」设计文档作为需求来源保留在 `docs/`。

## 🚀 AI 开工入口

> **接手本项目的 AI：第一件事是读 [`docs/开发指导总览.md`](docs/开发指导总览.md)。**

它包含：任务书与三条硬指标的验收定义、平台事实基线（能做什么 / 不能做什么 / 唯一可行路径）、总体架构与目录结构、28 个系统清单、美术管线、工具链、按次计费的工作流协议、M0–M12 里程碑、可直接复制的开工提示词。
