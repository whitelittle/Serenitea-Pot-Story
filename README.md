# 提瓦特生活模拟 · Teyvat Life Simulation

用「千星奇域客户端脚本」做一款**星露谷式的完整生活模拟游戏**，舞台是**整个提瓦特**——蒙德、璃月、稻妻、须弥、枫丹、纳塔、至冬。

三条要求：**系统完善、美术优秀、可玩性高**。
